# Code of Conduct

This project is committed to a welcoming, respectful, and harassment-free community for everyone.

## Our Standards

- Be respectful and constructive in discussions, code reviews, and issue threads.
- Assume good intent, but take responsibility for the impact of your words and actions.
- Welcome feedback, different perspectives, and contributors with different levels of experience.
- Do not engage in harassment, discrimination, personal attacks, or disruptive behavior.

## Scope

This Code of Conduct applies to project spaces, including issues, pull requests, discussions, code reviews, and other community interactions related to this repository.

## Reporting

If you experience or witness unacceptable behavior, contact the repository maintainers privately through an available non-public channel. Please avoid opening a public issue for conduct reports.
